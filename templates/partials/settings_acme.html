ACME server

CertMate answers ACME (RFC 8555) itself, from a root of its own, so certbot, lego, acme.sh and cert-manager can get certificates for your internal names. Who may enrol, and for which names, is set by the EAB keys below.

Options

At 45, the clients measured renew between days 30 and 37.5, a week or more before expiry.

Give clients this directory URL

Clients must trust this server's TLS certificate, and the hosts that use the certificates must trust the ACME root: download it and install it in their trust stores.

New EAB key

A name, or *. and a name for every name below it. A key is disabled, never deleted, so the accounts it enrolled stay attributable to it.
