{# The dashboard's own controls, living in the global topbar (#359). These used to be a band at the top of the page content: the view toggle on the left, the certificate counters on the right, and an empty row between them and the table. Moving them into the topbar frees that whole row on the one page where vertical space is worth the most. The topbar is shared by every page, so this renders only on `/` — the toggle and the counters are about certificates, and there is nothing for them to toggle anywhere else. `x-data` makes this an Alpine root, and the state it reads is the `certs` store registered at the top of this file — because the control that writes the view and the panels that read it are now in two different templates and cannot share an `x-data` scope. The registration ships with the only markup that reads it, so a page cannot end up with one half and not the other. Element ids are unchanged — `#statsCards` is where `updateStats()` writes, `#totalCount`/`#activeCount`/`#revokedCount` are where `ccLoadStatistics()` writes, and the command palette clicks `#certViewServerBtn` / `#certViewClientBtn` to change view. Only the surrounding layout moved. The breakpoint is `xl` (1280px) because that is where the three clusters measure as fitting: 64px of logo, 596px for this one (a 296px toggle, a 252px counter strip, the gap and its own padding) and a 443px icon rail come to 1103px, against the 1216px inside the `max-w-7xl` container at 1280 and the 1136px at 1200. The 1100px this was first written against is not enough — the cluster lands in the bar and then wraps inside itself, leaving a 108px-tall navigation, which is worse than giving it a row. #}
