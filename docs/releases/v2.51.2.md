## v2.51.2 (a pass over the web interface)

A patch release. It changes no feature and no API; every change is to the web UI, from a UX/UI review. It fixes controls that did nothing, controls that did the wrong thing, and text that named buttons the interface no longer has.

- **The creation drawer opens from where it should.** The `n` shortcut and the setup wizard's final button open the New Certificate drawer instead of pointing at markup the redesign had removed.
- **The certificate table holds its shape.** Pending "Issuing" and "Failed" rows now carry every column the header has, and the check-all control disables itself and shows progress while it runs.
- **The inventory is reachable.** It has a place in the mobile tab bar and two entries in the command palette, and the palette now flashes the client certificate it jumps to.
- **The CA account dialog no longer fights the settings form.** It moved out of the form, so a required field in it no longer blocks the page and Enter inside it no longer submits the whole page. The CA tab also stops showing the page-wide "Save Settings" bar, which saved nothing of that tab.
- **The Probe protocol pickers announce their state** and close on Escape, and the Add Probe row wraps on a narrow screen instead of overflowing.
- **The reset-password prompt masks what you type**, and settings dialogs no longer double-escape a name or filename in their text.
- **Reopening Settings refills every provider's DNS credentials.** A provider configured through the single-account form (scaleway, he-ddns, ovh, godaddy and the rest, not only the first nine) came back blank and looked unconfigured.
- **The DNS account dialogs leave the page scroll as they found it.**
- **Escape over a certificate's detail panel** dismisses the dialog on top of it, not the panel underneath.
- **The login form drops the "Remember me" checkbox**, which was never read.
- **The first-run setup screen stands alone.** It no longer loads the app's navigation and live event stream before any admin exists; its errors are shown inline, its password field masks and toggles, and its button locks while setup runs.
- **Creating, revoking or renewing a client certificate** reports the real reason on failure and cannot be fired twice by a double click.
- **Help and empty-state text name the real controls:** the API bearer token on the General tab, the CA dialog's "Check configuration" and "Save Account", probe targets on the Probe tab, and the dashboard's Create Certificate button.

The API contract is unchanged (**2.56**).
